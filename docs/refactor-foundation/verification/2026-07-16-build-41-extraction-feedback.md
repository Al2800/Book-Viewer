# Build 41 Extraction Feedback

## Device Evidence

TestFlight feedback `AOjG3KiBCPfprvbc87qDmCQ` was submitted from Build 41 on an iPhone 17
running iOS 26.5.2. The screenshot shows 18 quote cards although the reader reports only two
margin-marked passages. Every visible source badge says `On-device`; remote AI was not used.

Several cards also display short OCR fragments such as `Su "I ta pr kr b th` in the margin-note
field. These were generated by the local selector treating nearby printed OCR as handwritten notes.

## Root Causes

- Build 41 could not grant remote-processing consent through the temporary TestFlight access path,
  so sign-in alone still left the extraction pipeline local-only.
- Local mark geometry accepted printed glyph strokes as underlines, brackets, or mixed marks.
- Nearby OCR was inferred as a margin note without reliable handwriting classification.
- A successful remote response containing no quotes was discarded in favor of local OCR.
- Onboarding marking selections were visual only; they were not persisted to the extraction
  vocabulary, while every seeded system marking remained enabled.

## Build 42 Corrections

- Remove local nearby-OCR margin-note inference.
- Reject underline strokes embedded inside printed text and vertical marks inside body-text bounds.
- Ignore ambiguous `mixed` marks locally and filter local marks to the reader's enabled families.
- Fail closed when local detection produces more than eight review candidates.
- Make the model prompt precision-first and require uncertain marks and notes to be omitted.
- Treat a successful model response as authoritative, including an empty quote list.
- Persist onboarding marking choices and exclude `mixed` from selectable styles.
- Show an explicit review notice whenever remote processing was disabled.
- Pause the first eligible TestFlight capture for the remote-processing consent decision instead
  of silently starting local analysis while consent is absent.
- Add the missing `double_underline` and `margin_line` values to the default model schema guidance.

## Verification

The complete `BookQuotesTests` unit bundle passed on the iPhone 17 Pro iOS 26.5 simulator. Focused
reruns also passed for the on-device extractor, model-first pipeline, consent presentation policy,
prompt builder, onboarding selection state, persisted marking definitions, extraction review, and
capture file handling.

The corrected Build 42 was archived from commit `0dab41e`, uploaded successfully, and completed
App Store Connect processing on 2026-07-16. It is `Ready to Submit` with no missing-compliance
warning and is assigned to the internal `Test v1` group. The earlier Build 42 archive was deleted
before this replacement archive was created.
